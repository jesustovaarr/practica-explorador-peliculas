# Explorador de Películas

Aplicación web interactiva desarrollada con **React** y el empaquetador **Vite** para la exploración y visualización de un catálogo cinematográfico popular. Este proyecto implementa una arquitectura desacoplada donde el frontend no consume directamente las APIs públicas de terceros; en su lugar, se apoya en un proceso de ingesta en Node.js que normaliza y persiste la información en **Supabase** bajo un esquema dedicado.

---

## Características Principales

* **Autenticación Externa (OAuth con GitHub):** Control de acceso seguro gestionado por **Supabase Auth** vinculado a una aplicación OAuth en GitHub, permitiendo el ingreso seguro incluso a usuarios con correo privado (`Allow users without an email`).

* **Arquitectura Desacoplada:** El cliente web consume de forma exclusiva la base de datos de Supabase, respetando las restricciones de persistencia antes de visualización.

* **Ingesta Masiva Idempotente:** Script en Node.js que consulta la API de **The Movie Database (TMDb)** en español (`es-MX`), descarga múltiples páginas de producciones populares y aplica operaciones `upsert()` tomando como conflicto el identificador `tmdb_id` para evitar duplicidades.

* **Diseño Cinematográfico Estilo Streaming:** Interfaz inmersiva con tema oscuro, acentos en rojo institucional, micro-interacciones hover con elevación y oscurecimiento sobre los pósters.

* **Paginación Dinámica:** Organización del catálogo en bloques de doce películas por página con navegación fluida.

* **Búsqueda Reactiva en Tiempo Real:** Filtrado instantáneo en memoria sobre el catálogo por título o año de estreno sin peticiones HTTP redundantes.

* **Vista Modal de Detalle:** Ventana emergente al seleccionar cualquier película con cabecera panorámica en alta resolución (`backdrop_url`), póster, sinopsis narrativa, año, volumen de votos de la audiencia y popularidad.

## Estructura de la Base de Datos (Supabase)

La base de datos PostgreSQL en Supabase organiza los datos en un esquema aislado para esta práctica:

* **Esquema:** `peliculas`
* **Tabla:** `catalogo`

```sql
CREATE SCHEMA IF NOT EXISTS peliculas;

CREATE TABLE IF NOT EXISTS peliculas.catalogo (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    tmdb_id INT NOT NULL UNIQUE,
    titulo TEXT NOT NULL,
    year TEXT,
    sinopsis TEXT,
    poster_url TEXT,
    backdrop_url TEXT,
    calificacion NUMERIC(3, 1),
    votos INT,
    popularidad NUMERIC(7, 2),
    creado_en TIMESTAMPTZ DEFAULT NOW()
);
```

## Guía de Instalación y Ejecución Local

### 1. Clonar el repositorio
```bash
git clone https://github.com/jesustovaarr/practica-explorador-peliculas.git
cd practica-explorador-peliculas
```

### 2. Instalar dependencias
```bash
npm install
```

### 3. Configurar variables de entorno
Crea un archivo `.env` en la raíz del proyecto a partir de la plantilla:

```bash
cp .env.example .env
```

Define tus credenciales en el archivo `.env`:

```env
# Variables accesibles desde React (Frontend)
VITE_SUPABASE_URL=https://tu-proyecto.supabase.co
VITE_SUPABASE_ANON_KEY=tu-anon-key-de-supabase

# Variables para el script de ingesta (Node.js)
TMDB_API_KEY=tu-api-key-de-tmdb
```

### 4. Ejecutar la ingesta inicial del catálogo
Descarga y sincroniza las producciones populares hacia la tabla `peliculas.catalogo` de Supabase:

```bash
node syncMovies.js
```

### 5. Iniciar el servidor de desarrollo
```bash
npm run dev
```

Abre tu navegador en la dirección indicada por la consola (habitualmente `http://localhost:5173`).
